# Набор AutoLISP утилит для работы с dwg-файлами

## Состав набора
Наименования утилит соответствуют командам вызова соответствующей утилиты.

- ADDLAY

    Создаёт вкладки листов с видовыми экранами для объектов в пространстве модели с масштабом 1:1. Основное назначение - создание листов при размещении рамок (форматок) в пространстве модели.

    В соответствие с размером видового экрана. полученного на основе размера рамки в модели, задаёт созданному листу параметры печати. Параметры печати при этом должны быть вида "PDF A B", где A - наименование формата, B - ориентация (P - книжная, L - альбомная), например "PDF A3x4 L", "PDF A0 P", "PDF A4x6 L" и т.д. Если в файле отсутствуют параметры листа под соответствующий размер формата, то назначение параметров данному листу не выполняется. Характеристики параметров листов (принтер, формат и т.д.) определяются пользователем.

    Поддерживается создание листов в порядке слева направо сверху вниз: при выделении прямоугольного массива рамок сперва будут созданы вкладки листов для самого верхнего ряда рамок, затем более нижнего и т.д. до конца. Группировка листов в ряды выполняется на основании пересечений Y-координат рамок, то есть Y-координата самой верхней либо самой нижней точки рамки должна находится между Y-координатами самой верхней и самой нижней точки другой рамки.

    В качестве рамок могут использоваться только прямоугольники (полилинии) либо блоки форматов (основных надписей), работа функции с рамками в виде отрезков не предусматривается.

- AS

    Добавляет символы в начало или в конец текста, например: было "KL1", "KL2", "KH1", "R1", после применения стало "01KL1", "01KL2", "01KH1", "01R1".

- ARRTXT

    Выравнивает разноупорядоченный текст относительно точки размещая его через одинаковые интервалы. Выравание возможно только вертикально либо горизонтально. Порядок текста определяется убыванием Y-координаты точки вставки при вертикальном упорядочивании, при горизонтальном упорядочивании - возрастанием X-координаты. 

- ATTRTXTSTYLE

    Изменяет текстовый стиль всех атрибутов блоков в чертеже на выбранный.

- AUDPRG

    Одновременное выполнение команд AUDIT и PURGE. Вызов PURGE удаляет все неиспользуемые объекты.
    
- DMPO

    Выводит дамп выбранного объекта.

- DS

    Удаляет заданое количество текстовых символов в начале или в конце текста, многострочного текста, выноски, первого атрибута блока.

- EXPLPLINES

    Преобразует выделенные пользователем полилинии с двумя точками в отрезки.

- GETTEXT

    Для выделенного однострочного, многострочного текста и выносок извлекает значения текстовой строки и выводит в консоль, фильтрует уникальные значения.

- GOTT

    Получение текстовых величин, встречающихся только один раз среди выбранных текстовых объектов. Выводит в консоль.

- NCAUDPRG

    Аналог AUDPRG для nanoCAD.

- NUMB

    Нумератор текстов, атрибутов блоков, мультивыносок. Нумеруется первый атрибут по порядку следования при выборе нумерации блоков. Возможна групповая или поочерёдная нумерация объектов. При выборе блоков в групповой нумерации нумеруется первый атрибут в блоке.

- NUMBB

    Нумератор атрибутов блоков, позволяет задать для нумерации выбранный атрибут.

- PRDXF

    Выводит DXF-данные выбранного объекта.

- PRG

    "Тихое" выполнение команды PURGE, без открытия диалогового окна очистки чертежа. Удаляет все неиспользуемые объекты.

- TRIMTEXT

    Удаляет пробелы в начале и в конце текста (однострочного) по всему чертежу.
